# Цей проєкт розроблено в рамках лабораторної роботи для демонстрації практичних навичок роботи з інструментами автоматизації розробки. Головна мета — налаштування процесів безперервної інтеграції (CI) та автоматичного контролю якості коду.

# 

# \*\*Основні можливості проєкту:\*\*

# \* \*\*Математичний модуль:\*\* реалізація базових арифметичних операцій (додавання, віднімання).

# \* \*\*Автоматичне тестування:\*\* інтеграція модульних тестів (Unit-тестів) для верифікації логіки розрахунків.

# \* \*\*Статичний аналіз коду:\*\* автоматична перевірка синтаксису та форматування коду на відповідність стандартам PEP8 за допомогою лінтера `flake8`.

# \* \*\*Захист коду:\*\* автоматичне приховування конфіденційних даних через механізм GitHub Secrets та блокування злиття неперевірених змін у гілку `main`.

# 

# \## Інструкція із запуску тестів локально

# 

# ```bash

# python -m unittest test\_calculator.py
